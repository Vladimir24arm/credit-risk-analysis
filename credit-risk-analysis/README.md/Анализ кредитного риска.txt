# Анализ кредитного риска (SQL / PostgreSQL)

## О проекте
Анализ портфеля банка: 150 000 клиентов. Цель — выявить факторы дефолта.

## Данные
— Источник: [Credit Risk Dataset — Kaggle](https://www.kaggle.com/)
— Объём: 150 000 строк, 11 колонок
— Поля: client_id, default_flag, credit_utilization, age, late_30_59, debt_ratio, monthly_income, open_credits, late_90_plus, late_60_89, dependents

## Инструменты
— PostgreSQL 16
— pgAdmin 4

## Что сделано
1. Загрузил данные в PostgreSQL.
2. Создал таблицу `credit_en` с английскими колонками.
3. Проверил качество данных (NULL, пропуски).
4. Очистил выбросы (`debt_ratio < 5`).
5. Сегментировал клиентов по 4 факторам.
6. Применил оконные функции (`RANK`).
7. Провёл комбинированный анализ.

## Ключевые выводы

### 1. Доля дефолтов — 6.68%. Из 150 000 клиентов 10 026 в дефолте.

### 2. Возраст — значимый фактор
Молодые (18—24) — 10.46%, пожилые (65+) — 4.52%.

### 3. По доходу слабая связь, 5—9% во всех группах.

### 4. Кредиты: 0 — красный флаг
Клиенты без кредитов — 25.64% дефолтов.

### 5. Просрочки 90+ — лучший предиктор, 3+ просрочки → 60.45% дефолтов.

### 6. Комбинация молодого возраста + просрочки = 44%
Группа молодых заемщиков самая рискованная.
